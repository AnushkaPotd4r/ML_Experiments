Multinomial Softmax

Computes probabilities across K mutual classes using normalized exponential logits:

P(Y=k | X) = ez_k / Σj=1K ez_j

Guarantees Σ P(Y=k) = 1.0, enabling continuous likelihood grading across all academic tiers.
