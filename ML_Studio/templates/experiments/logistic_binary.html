Sigmoid Logistic Function

The logistic model transforms linear log-odds into probabilities bounded between 0 and 1:

P(Y=1 | X) = 1 / (1 + e-z)

where z = β₀ + β₁·CGPA + β₂·IQ. The decision boundary corresponds to z = 0 where P(Y=1) = 0.50.
